# App Store Figma Editorial

Turn captured app screenshots into premium, benefit-led store slides using Figma MCP while preserving UI truthfulness.

## Core Rule
The UI is real. The design layer is editorial.

Never invent, redraw, or fake product states.

## File Structure
Create pages in this order:
- `01 Components`
- `02 iOS 6.7`
- `03 iOS 6.5`
- `04 Android`
- `05 Variants`

## Layout System
- One phone frame per slide.
- Keep UI at 55-65% of slide height.
- Keep text outside critical UI regions.
- Use generous padding and a clear focal point.
- Avoid repeating the exact same composition across slides 2-6.

## Typography
- Headline: 3-6 words, max 2 lines.
- Support line: optional and short.
- High contrast and large readable size.
- Use one headline style and one support style across the full set.

## Background Direction
Allowed:
- Soft gradients
- Radial or vertical blends
- Up to two color stops
- Subtle grain/noise (2-4%)

Not allowed:
- Stock photo backgrounds
- Loud illustrations
- Pure black blocks
- Backgrounds that compete with UI readability

## Exploded UI Technique
Use only when it improves value clarity.

Approved patterns:
- Single element hero
- Exploded element plus small anchored phone
- Stack explosion for cards/routines/collections

Hard rules:
- Explode one element only.
- Fade everything else.
- Do not explode trust/compliance screens.

## Slide-Specific Guidance
- `1` Hero: bold promise, minimal UI, implied motion allowed.
- `2-6` Benefits: one benefit per slide, vary composition.
- `7` Trust: cleaner and calmer, proof over drama.
- `8` Summary: no explosion, one anchor UI, 3-5 short benefit labels.

## Output Requirements
Produce:
- Final slide designs for iOS 6.7, iOS 6.5, and Android baseline.
- Three headline variants per slide.
- Figma share link in `figma/figma_file_link.txt`.

## Quality Gate
Fail if:
- UI is fabricated or misleading.
- Headline and image do not communicate the same benefit.
- Text is illegible on common phone previews.
- Slide set feels visually inconsistent or cluttered.
