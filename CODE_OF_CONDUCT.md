# Code of Conduct

Everyone participating in this project should have a respectful and welcoming
experience, regardless of background, identity, disability or level of experience.

Use considerate language, discuss ideas and evidence, credit others' work and respect
privacy. Constructive disagreement is welcome. Harassment, discrimination, threats,
sexualized conduct, personal attacks, doxxing and sharing private information without
permission are unacceptable.

This applies to issues, pull requests, reviews, discussions and project events, and
when representing the project elsewhere. Maintainers are responsible for applying
these standards fairly, including to themselves.

The release maintainer is [thedarkcder](https://github.com/thedarkcder). Report concerns privately through the maintainer's published contact channel. Do not
post someone's personal information in a public issue. Maintainers must designate
an enforcement contact before opening public contributions; the readiness report
tracks this unresolved operational decision.

Maintainers may remove inappropriate content, warn participants, temporarily restrict
participation or exclude participants for serious or repeated misconduct. Responses
should be proportionate, consider context and protect the reporter's privacy. A
participant may request reconsideration from a maintainer uninvolved in the incident
when one is available. Good-faith reports must not result in retaliation.

These community participation rules do not add restrictions to the software license.
